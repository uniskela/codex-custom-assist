# Codex Custom Assist

OpenAI-compatible **conversation agent** for Home Assistant Assist — configurable `base_url` + `api_key`, with [Codex-LB](https://github.com/soju06/codex-lb) as the primary example and other Chat Completions backends as configuration (not forks).

Secrets stay in the config entry. See the [README](https://github.com/uniskela/codex-custom-assist) for setup.
